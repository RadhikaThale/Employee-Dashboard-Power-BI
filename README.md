# Employee-Dashboard-Power-BI
An interactive Employee Dashboard built in Microsoft Power BI to
explore employee records and understand workforce distribution across
departments, business units, gender, employment status, and years.

Add your dashboard screenshot to this repository using the filename

Overview
The dashboard provides a consolidated view of employee data through
interactive visuals and filters. It is designed to help users explore
workforce composition and compare employee counts across different
organizational dimensions.
Dashboard Features
- Employee details table: Displays employee-level information such
  as Employee ID count, first name, gender code, department type, and
  employee status.
- Gender filter: Allows users to filter the dashboard by gender.
- Year-wise employee trend: A line chart showing employee counts
  by year.
- Department analysis: A horizontal bar chart comparing employee
  counts across department types.
- Department composition: A pie chart showing the proportion of
  employees in each department type.
- Business unit analysis: A bar chart comparing employee counts
  across business units.
- Interactive exploration: Power BI visual interactions and
  filters allow users to explore the data from different perspectives.
